JasimFlow v4.10 — PDF Export Stability Patch

Fixes:
1. Tech Grid: fixes "unsupported color function color" during Download PDF.
2. Replaces old html2pdf/html2canvas engine with html2canvas-pro 1.6.7 + jsPDF 4.2.1 (loaded at runtime, no npm package install required).
3. PDF is rendered from a hidden full-size A4 clone, not from the mobile scaled preview.
4. Fixes missing/clipped text seen in several templates.
5. Locks Minimal Ledger export geometry to prevent text/layout drift.
6. Ensures PDF export temporary DOM is always removed after success/failure.
7. Adds generation timeouts so Download/Share buttons cannot stay permanently locked after a rendering failure.
8. Share uses the same corrected PDF generator.

No Supabase SQL is required.
No npm install is required.

After extracting over the JasimFlow project root:
  npm run build
  git add .
  git commit -m "Fix PDF export and template rendering"
  git push
